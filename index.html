PROJECT WALKTHROUGH

RAG Chatbot — Open-Source LLM Stack

An end-to-end Retrieval-Augmented Generation pipeline built entirely on open-source Hugging Face models — no paid LLM APIs. This diagram shows how a document turns into a grounded, cited answer.

sentence-transformers/all-MiniLM-L6-v2 FAISS Qwen2.5-1.5B-Instruct Hugging Face Transformers
1
INGEST

Chunk the source documents

Raw text/PDF documents are split into overlapping ~300-character chunks using a recursive character splitter — small enough for precise retrieval, with overlap so ideas aren't cut mid-sentence.

2
EMBED

Convert chunks to vectors

Each chunk is encoded into a 384-dimensional embedding using all-MiniLM-L6-v2 — small, fast, and fully open-source, runs comfortably on CPU.

3
INDEX

Build a FAISS vector index

Normalized embeddings are loaded into a FAISS inner-product index, enabling fast cosine-similarity search across every chunk.

4
RETRIEVE

A question comes in

The user's question is embedded with the same model, then FAISS returns the top-k most semantically similar chunks — the grounding context for the answer.

5
GENERATE

The LLM answers — grounded in context

Retrieved chunks are placed in a system-instructed prompt sent to Qwen2.5-1.5B-Instruct, using greedy decoding to stay literal and reduce hallucination.

6
RESPOND

A grounded answer, back to the user

The chatbot replies using only what was retrieved — traceable back to the source documents rather than the model's own memorized knowledge.
